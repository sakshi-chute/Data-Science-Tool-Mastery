# Data Science Tool Mastery Project

## Project Overview

The Data Science Tool Mastery Project is designed to develop practical knowledge and technical skills in essential Python libraries and tools used in Data Science. This project focuses on data manipulation, data cleaning, numerical computation, statistical analysis, and data visualization.

Through practical exercises and a mini-project, this project demonstrates how different Python libraries can be used together to analyze datasets and generate meaningful insights.

## Objectives

- Understand industry-standard Data Science tools and libraries.
- Learn numerical operations using NumPy.
- Perform data manipulation and analysis using Pandas.
- Handle missing values and duplicate records.
- Create visualizations using Matplotlib and Seaborn.
- Perform practical data analysis using Python.
- Develop a mini-project to demonstrate technical skills.

## Mini Project: Student Performance Analysis

### Description

The Student Performance Analysis mini-project analyzes students' academic marks using Python and its Data Science libraries.

The project stores student details and subject marks, calculates total and average marks, identifies the highest and lowest performers, and presents the results through graphical visualizations.

### Features

- Student marks management.
- Total marks calculation.
- Average marks calculation.
- Identification of highest and lowest scores.
- Student performance comparison.
- Bar chart visualization.
- Subject correlation heatmap.

### Libraries Used

- NumPy
- Pandas
- Matplotlib
- Seaborn
